Limbaje:

  • HTML

    It is the fundamental language used to structure the content of a web page, defining elements such as titles, text, images, and links.

  • CSS

    It allows styling of HTML elements and controls the visual appearance of the website, including colors, fonts, layout, and graphic effects.

  • JavaScript

    A programming language that adds interactivity to web pages, allowing dynamic actions and real-time content updates.

  • Node.js

    A runtime environment that allows JavaScript to run on the server side, enabling fast, scalable, and efficient backend development.

  • Express.js

    A lightweight web framework for Node.js that simplifies building APIs and server-side applications with powerful routing and middleware features.

  • MongoDB

    A database that stores data in flexible, JSON-type documents, facilitating the management of large, unstructured, and constantly evolving data sets.

  • PHP

    A server-side programming language used for generating dynamic content and interacting with databases in web applications.

  • MySql

    A relational database management system used to efficiently store and organize a website's data.
